## 🌐 1-Click Deployment Options

### Deploy to GitHub Pages (Free & Recommended)
1. Initialize git and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sachin Shinde PM Portfolio"
   ```
2. Create a new repository on your GitHub account (e.g., `pm-portfolio` or `sachinshinde.github.io`).
3. Push to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings ➔ Pages ➔ Source** and select **`main` branch / `root` folder**. Your site is live!

### Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this folder and follow the prompts. Live in ~15 seconds.
